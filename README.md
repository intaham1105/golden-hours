# 골든타임

의대 정원 증원 반발 총파업 시기, 집에서 쓰러진 플레이어가 골든타임 안에 받아줄 병원을 찾아가는 픽셀 웹게임 (도입부 프로토타입).

## 실행
- 내 컴퓨터: `index.html`을 브라우저(크롬, 엣지 등)로 열면 됩니다. 설치할 것은 없습니다.
- 웹사이트: GitHub Pages로 올립니다 (아래 "웹사이트에 올리기").

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 |
| `firebase-config.js` | Firebase 설정값. 비워 두면(`null`) 서버 없이 동작 |
| `firestore.rules` | Firebase 데이터 보안 규칙 (이름 중복 금지, 본인 기록만 읽고 쓰기) |
| `manifest.webmanifest`, `icon-*.png` | 휴대폰 홈 화면에 추가할 때 쓰는 앱 정보와 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리게 하는 빈 파일 |

## 웹사이트에 올리기 (GitHub Pages)
1. 이 폴더의 파일을 GitHub 저장소에 올린다 (`main` 브랜치 맨 위에 `index.html`이 있게)
2. 저장소 → Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main** / **/(root)** → Save
3. 1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 에서 플레이

## 서버 연결 (Firebase · 무료)
연결하면 이름 중복을 **모든 플레이어** 대상으로 막고, 기록이 서버에 저장됩니다. 구글 계정을 연결한 플레이어는 다른 기기에서도 이어서 할 수 있습니다.
연결하지 않으면 각자 브라우저에 저장되고, 이름 중복은 그 기기 안에서만 확인합니다.

1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: golden-time, Google 애널리틱스는 꺼도 됨)
2. 프로젝트 개요 → **웹 앱 추가(</>)** → 앱 닉네임 입력 → 등록 → 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여 넣기
   ```js
   window.GOLDEN_FIREBASE = { apiKey: "...", authDomain: "...", projectId: "...", appId: "..." };
   ```
   (이 값은 공개돼도 괜찮습니다. 데이터는 아래 보안 규칙이 지킵니다)
3. 빌드 → **Authentication** → 시작하기 → 로그인 방법에서 **익명** 사용 설정, **Google** 사용 설정
4. Authentication → 설정 → **승인된 도메인** → 도메인 추가: `<깃허브아이디>.github.io`
5. 빌드 → **Firestore Database** → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
6. Firestore → **규칙** 탭 → 내용을 모두 지우고 `firestore.rules` 내용을 붙여 넣기 → **게시**
7. 바뀐 `firebase-config.js`를 저장소에 올리면 끝. 게임 설정 창에 "저장 위치: 서버"가 보이면 연결된 것

## 테스트용 주소
- 주소 뒤에 `?debug`: 개발용 연결(`window.__golden`) 켜기
- `?debug&rich`: 갑부로 시작
- `?guitar`: 기타 병원 엔딩 확정 (디버그 없이 누구나)

## 조작
- 이동: 방향키 / WASD (터치 기기는 화면 왼쪽 아래 방향키)
- 대화 넘기기: Space, Enter, 클릭
- 휴대폰: 오른쪽 아래 휴대폰 버튼, Esc로 닫기
- 다시 하기: 오른쪽 위 "↻ 다시 하기" 버튼 또는 R 키 (2초 안에 한 번 더 눌러야 처음부터 시작)
- 운전: 방향키를 누르는 쪽으로 달림 (최고 120km/h). 옆 방향키는 차선 변경, 교차로 전에 미리 누르고 있으면 꺾을 수 있을 때 꺾음
- 차에 타면 왼쪽 아래 내비: 주변 길 전체, 병원(분홍 십자, 목적지는 깜빡이는 빨간 십자), 가야 할 길(노란 화살표). 도로 위에도 노란 화살표 표시
- 신호등: 교차로마다 8% 확률로 빨간불 → 10~30초 자동 정지 (`RED_CHANCE`로 조정)
- 우측 통행: 진행 방향 오른쪽 2개 차선만 달릴 수 있음
- 바리케이드: 차선 하나가 막혀 있어 옆 차선으로 바꿔 지나가야 함
- 다른 차는 내 차 앞에서 멈춤. 내가 같은 차선에서 들이받을 때만 사고(-1분), 옆 차선으로는 부딪히지 않고 추월 가능
- 도로 위 차량: 승용차, 가끔 택배 트럭·초대형 트레일러 트럭, 파란 스포츠카 10대(동네마다 2대). 지인의 차는 보통 파란 승용차, 13% 확률로 노란 람보르기니(최고 175km/h, 가속도 훨씬 빠름)
- 키보드 다이얼: 전화앱에서 숫자·*·# 입력, Backspace 지우기, Enter 통화
- 실패 연출: 시간 0 → 화면 흔들림·흑백/핏빛 → 약해지는 심전도 → 심정지 평탄선 → 암전 → 게임오버
- 도착하면 의료진이 들것을 들고 나오고, 화면이 어두워진 뒤 응급 처치실 장면

## 휴대폰
- 같은 주소에서 그대로 됩니다. 손가락 기기면 자동으로 휴대폰 화면이 됩니다
- 조이스틱: 화면 아무 데나 누르고 끌면 그 자리에 스틱이 생김 (걷기는 대각선도, 운전은 민 방향으로). 손을 떼면 흐리게 기본 자리(걷기 왼쪽 아래, 운전 오른쪽 아래)로 돌아감
- 화면이나 대화창을 탭하면 대화 넘기기
- 가로로 들고 하는 게임입니다. 세로로 들면 화면이 옆으로 돌아가 있으니 휴대폰을 가로로 돌리면 꽉 찬 화면이 됩니다 (자동 회전이 꺼져 있어도 됨)
- 안드로이드: 시작하기를 누르면 전체 화면 + 가로 고정
- 아이폰: 사파리 공유 버튼 → "홈 화면에 추가"하면 주소창 없이 전체 화면 앱처럼 실행
- 아이폰은 무음 스위치가 켜져 있으면 소리가 나지 않습니다

## 플레이어 · 저장 · 설정
- 처음 열면 플레이어 이름(2~10자, 한글·영문·숫자)을 만듦. 이미 있는 이름은 쓸 수 없음 (대소문자 구분 없음)
  - 클로드 아티팩트에서 열면: 클로드 계정마다 저장되고, 이름 중복은 이 아티팩트를 하는 **모든 플레이어** 대상으로 확인
    (다른 사람이 저장하려면 아티팩트를 "참여자(Contributor)" 이상으로 공유해야 함. 보기 전용이면 그 사람 브라우저에만 저장)
  - 웹사이트 + Firebase 연결: 서버에 저장, 이름 중복은 모든 플레이어 대상, 구글 계정 연결 시 다른 기기에서도 이어짐 (위 "서버 연결")
  - 파일로 열거나 Firebase 없이 올리면: 이 기기 브라우저에 저장, 이름 중복은 이 기기 안에서만 확인
- 자동 저장: 엔딩 도감, 설정, 기록(플레이 수, 생존 수, 최고 남은 시간), 진행 중인 판
- 이어하기: 타이틀의 "이어하기"로 마지막 저장 지점부터 (집에서 전화하는 중 / 친구 기다리는 중 / 운전 중 위치·목적지 / 구급차). 같은 동네·연락처가 그대로 다시 만들어짐
- 설정: 배경음·효과음 볼륨, 화면 흔들림, 대사 빠르게. 타이틀 또는 게임 중 오른쪽 위 "⚙ 설정" (여는 동안 게임 멈춤)
- 소리: 상황별 배경음이 자연스럽게 바뀜 (타이틀, 집, 대저택, 위급, 운전, 남은 시간이 적으면 긴박한 음악, 병원에서는 잔잔한 클래식, 로봇·헬기, 기타, 성공·실패 엔딩). 쓰러짐·노크·통화 연결음·충돌·변신·처치실 심전도 효과음. 효과음, 발소리, 운전 중 엔진 소리(속도 따라), 구급차 사이렌

## 흐름
1. 집에서 걷다가 응급 상황 발생 → 골든타임 30분 시작 (실제 3분, 1초 = 게임 10초)
2. 휴대폰 → 전화 → 키패드로 119에 3번 전화 (모두 거절, 회당 -2분)
3. 루트 선택
   - 즐겨찾기 지인 → 친구 도착 → 친구가 업고 나가서 차 탑승 → 월성동 지도에서 직접 운전, 차 안에서 친구가 병원에 다시 전화 → 동쪽으로 이어진 동네 4곳 중 2~4번째 동네 병원까지 운전 (왕복 4차선 도로, 가끔 있는 공사중 구간은 돌아가야 함)
   - 검색창에 "의사" → 동네 병원은 "소형이라 수술 불가"로 거절(-2분), 10% 확률로 나오는 "OOO(의사)" 친구는 근처 병원과 연결 → 구급차 엔딩
4. 없는 번호에 전화하면 -1분, 운전 중 충돌하면 -1분 (3번째 사고는 사고 엔딩)
5. 운전 중 남은 시간이 3분이 되면 의식이 끊기기 시작함 (화면 암전, 지인이 "조금만 더 힘내")
6. 5% 확률로 갑부로 시작: 대저택 2층에서 쓰러지고, 119 대신 연락처에서 집사를 부름 → 집사가 업고 바로 앞 대형병원 → 병원장 면담 → 수술

## 지도
- 월성동: 기준 지도와 같은 배치 (아파트 단지, 학교, 공원, 신사, 주택가, 마트, 편의점, 월성대학병원, 상점가, 광장, 도서관, 체육관, 주차장, 역, 선착장, 다리, 초등학교, 병원(분원), 해변, 등대)
- 나머지 4개 동네: 같은 스타일로 매 판 새로 생성, 동쪽 큰길로 이어짐

## 조정값
`index.html`의 `// ───── 설정 ─────` 부분: `GOLD`(골든타임), `RATE`(시간 배속), `CAR_MAX`(차 최고 속도), `NT`(동네 수), `DOC_FRIEND_CHANCE`(의사 친구 확률), `RICH_CHANCE`(갑부 확률), `LAMBO_CHANCE`(람보르기니 확률), `HELI_CHANCE`·`GUITAR_CHANCE`(숨겨진 엔딩 확률), `LAMBO_MAX`·`LAMBO_ACC`(람보르기니 성능), `EVAN_NEED`(숨겨진 엔딩 조건 수)
